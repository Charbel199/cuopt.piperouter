Applications

What You Can Build

Route any wire, cable, or fluid pipe through complex 3D geometry with collision avoidance, thermal awareness, and physical constraints - all in Omniverse.

Automotive Harness Routing

Route full automotive wire harnesses with up to 14 wire classes simultaneously through complex CAD-imported USD scenes, enforcing thermal melt limits and EMF separation constraints.

Multi-Wire Bundling

Group same-kind wires into shared trunk routes using combined-diameter physics (√Σd²). The two-phase bundle router finds the optimal shared trunk before splitting into individual branches.

Constraint-Aware Paths

Define hard constraints (collision, clearance, waypoints) and soft penalties (surface-hug, bend radius, thermal avoidance, EM avoidance) through interactive UI sliders - paths update in real time.

Deep Dive

Core Components

Six specialized modules, each with a precise role in the routing pipeline - from raw USD geometry to smooth, physics-valid tube paths authored back into the stage.

Warp Voxelizer
GPU
Converts USD meshes to a 3D occupancy + field grid
  • Winding-number sign test for inside/outside classification
  • Thermal field and EM field layers baked alongside occupancy
  • ~1ms per rebuild after Warp JIT compilation warms up
  • Configurable voxel resolution; supports incremental rebuild on scene change
Lattice Builder
GPU
Expands voxel grid to heading-expanded state space
  • Each cell split into N heading buckets (6 / 18 / 26 connectivity)
  • Edge costs encode bend penalty, thermal, EM, and surface-hug soft weights
  • cupy zero-copy transfer directly into cuGraph - no host round-trip
  • Supports directional departure constraint from connector orientation
cuGraph SSSP
GPU
Dijkstra shortest-path on the heading-expanded directed graph
  • ~270ms per wire on a typical automotive scene (A100 class GPU)
  • Handles millions of nodes; heading expansion enables in-plane curvature control
  • Automatic CPU fallback via scipy when no NVIDIA GPU is available
  • Path decoded back to 3D cell centers for downstream smoothing
Fibre-Neutre Smoothing
CPU
Global energy minimization for physically valid polylines
  • Least-squares energy: bending stiffness + tension + obstacle repulsion
  • Hard-safe obstacle loop: post-optimization collision re-check and push-off
  • Waypoint pass-through constraints enforced as equality constraints
  • Output polyline respects minimum bend radius for the wire class
Bundle Router
CPU
Groups same-kind wires into shared trunk + branches
  • Two-phase: solve shared trunk first, then route individual branches
  • Combined bundle diameter = √(Σdᵢ²) - physical cross-section packing
  • Trunk clearance inflated to account for combined bundle girth
  • Per-bundle visual style (color, radius) in Omniverse viewport
Constraint Engine
CPU
Hard and soft constraint management for routing decisions
  • Hard: collision-free, clearance band, thermal melt temperature, waypoints
  • Soft sliders: surface hug, bend minimization, thermal avoidance, EM avoidance
  • Wire class library: 14 types with diameter, bend radius, and temperature limit
  • Design-space zones: include / exclude regions defined from USD primitives
Pipeline

End-to-End Routing Pipeline

Eight deterministic steps from raw USD stage to fully authored BasisCurves tubes - each step traceable and debuggable independently.

01
Load USD Stage KIT
Omniverse Kit extension traverses the active USD stage, extracting all mesh prims flagged as obstacles or design-space zones.
02
Warp Voxelize GPU
scene_ops feeds mesh triangles into the Warp kernel. Winding-number test classifies each voxel as free / solid / margin. Thermal and EM scalar fields are baked in parallel. Result: 3-channel GridStack tensor.
03
Save GridStack → /dev/shm
The GridStack numpy array is written to /dev/shm (shared tmpfs). Zero-copy memory-mapped by the solver container - no serialization overhead.
04
HTTP POST /solve_all
RouterSession serializes all wire specs (start/end points, class, constraints, soft weights) as JSON and POSTs to the FastAPI solver container endpoint.
05
Build Heading-Expanded Graph GPU
Lattice Builder expands the occupancy grid into a (cell × heading) directed graph on GPU via cupy. Edge weights encode all soft constraint costs. Zero-copy hand-off to cuGraph.
06
cuGraph SSSP - Dijkstra GPU
cuGraph runs Dijkstra on the heading-expanded graph (~270ms per wire). Path decoded back to 3D voxel-center coordinates. If GPU unavailable, scipy.sparse Dijkstra is the automatic fallback.
07
Fibre-Neutre Smoothing
Least-squares global minimization converts the voxel-staircase path to a smooth polyline. Hard-safe obstacle loop post-checks and pushes waypoints off geometry. Waypoint pass-through constraints enforced exactly.
08
Author BasisCurves Tubes in USD KIT
scene_ops writes BasisCurves prims with per-wire radii, material assignments, and optional bundle grouping. Debug overlay prims optionally authored alongside production geometry.
Prerequisites

Technical Requirements

PipeRouter targets GPU-equipped workstations with the NVIDIA Container Toolkit. A CPU-only fallback is available for the solver (scipy), but the Warp voxelizer requires CUDA.

Component Requirement
NVIDIA GPU Ampere architecture or newer (A100, RTX 3080+, RTX 4090) for cuGraph and Warp REQUIRED
CUDA Toolkit CUDA 12.x with matching NVIDIA driver. Tested on CUDA 12.4 and 12.6.
Omniverse Kit Kit SDK 110.x - extension loaded via ext_manager. Kit 106 not supported.
Docker Docker Engine 24+ with NVIDIA Container Toolkit (nvidia-docker2). GPU passthrough required for the solver container. REQUIRED
Python Python 3.12 inside the solver container. Kit extension uses Kit's bundled Python 3.11.
cuGraph RAPIDS cuGraph 24.x - installed in the solver container image via conda-forge.
Warp NVIDIA Warp 1.x - installed as an Omniverse extension dependency.
